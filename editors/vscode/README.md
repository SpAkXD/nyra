# Nyra for VS Code

Syntax highlighting for `.nyra` files, including expressions inside `{ }` in strings.
Semicolons are highlighted as errors.

## Install (from this repo)

Copy this folder into your VS Code extensions folder and reload VS Code:

```bash
cp -r editors/vscode ~/.vscode/extensions/spakxd.nyra-0.2.0
```

On Windows the folder is `%USERPROFILE%\.vscode\extensions\`.
