Each run gets 100 million steps, 256 MB of memory, 1 MB of output, 5 seconds and 500 nested calls. A program that goes over stops with an error code, never with a frozen tab.

  






  

    
The real compiler
The same Rust source as the nyra command, built to WebAssembly with no crates and no bindings generator: about 1.4 MB.

    
Sandboxed by design
Programs run in the interpreter of nyra run --sandbox, in a worker, with limits on steps, memory, output, time and depth.

    
Capabilities, live
Only input is granted here. A use fs or use os is error E0290 before anything runs: try the use fs example.
