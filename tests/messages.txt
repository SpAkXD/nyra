# Golden file for the compiler's diagnostics (tests/messages.rs).
#
# Every case is a small bad program followed by the exact text `nyra check case.nyra` prints
# for it:
#
#     ==== name            starts a case
#     <the program>
#     ----
#     <the expected output>
#
# Invisible characters are written \u{XXXX}. After changing a message on purpose, rewrite the
# expected text with:  NYRA_BLESS=1 cargo test --test messages
# and review the diff: it is the change your users will see.
